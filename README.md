# ML Cyber — антиспам-классификатор

Итоговый проект по машинному обучению: классификация электронных писем
`ham/spam`, сравнение моделей и готовый сервис на FastAPI в Docker.

- [Основной ноутбук с выполненными ячейками и графиками](PROJECT_antispam/project/PROJECT.ipynb)
- [Подробное описание и инструкции по запуску](PROJECT_antispam/README.md)
- [Результаты эксперимента](PROJECT_antispam/docs/RESULTS.md)
- [Запуск Docker и примеры API](PROJECT_antispam/docs/DOCKER.md)
- [Метрики, таблицы и графики](PROJECT_antispam/reports/)

## Структура репозитория

```text
ML_Cyber/
├── PROJECT_antispam/    # код, ноутбук, данные, модель, тесты и документация
├── easy_ham/            # исходные обычные письма
├── hard_ham/            # исходные сложные обычные письма
├── spam_2/              # исходные спам-письма
└── *.docx, *.pptx       # материалы задания и выступления
```

Сохранена структура локального проекта: исходные корпуса находятся рядом
с `PROJECT_antispam`, как ожидает код загрузки данных. В репозиторий включены
обработанные данные, внешний контрольный набор, обученная модель и результаты.
Виртуальное окружение, кэши и временные файлы исключены через `.gitignore`.

## Быстрый запуск

При установленном и запущенном Docker Desktop выполните в PowerShell:

```powershell
git clone https://github.com/city-cyber/ML_Cyber.git
cd ML_Cyber/PROJECT_antispam
.\start_docker.cmd
```

Интерактивная документация сервиса: <http://127.0.0.1:8000/docs>.
Остановка: `.\stop_docker.cmd`.

Для обучения и работы с ноутбуком используйте
[инструкции проекта](PROJECT_antispam/README.md#запуск-на-windows).
